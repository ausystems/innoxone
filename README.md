# INNOXONE homepage

Responsive homepage for INNOXONE personal golf mobility.

## Website

https://ausystems.github.io/innoxone/

## Update the homepage

Edit `source/content.json`, `source/page.js`, or `source/style.css`, then run:

```sh
node source/build.cjs
```

Commit the generated `index.html` together with the source changes. GitHub Pages publishes the root of `main`.

The site uses optimized WebP images, responsive videos, captions, and self-hosted fonts. No package installation is required to build.

The canonical URL remains https://www.innoxone.com/. Product and inquiry links lead to the existing INNOXONE website. No custom domain configuration is included.

Photography, product footage, and brand assets are supplied for this INNOXONE project. The font license is in `assets/Mona-Sans-OFL.txt`.
